## 🪞 观己是什么

**观己**是一个纯前端 AI 分析工具。

它做一件很简单的事：把你的聊天记录交给 AI，让 AI 读完你的对话后，以**你的口吻**讲述你的人生经历。

不是生成性格标签，不是画人格画像，而是**一段完整的人生叙事**——像你回忆自己过去一样自然。

### 它和"性格测试"的本质区别

性格测试给你分类——"你是 INFJ"、"你是 D型人格"。

观己不做分类。它输出一段经历，让 AI 通过这段经历去理解你。人不是标签的集合，人是矛盾的、变化的、不能被固化的。

## ✨ 功能

### 🛤️ 人生经历分析
- 上传微信或QQ导出的 TXT 聊天记录
- 智能解析多种导出格式（支持 6 种时间戳格式、中英文混合、系统消息过滤）
- 字符预算分配算法（时间分层 + 均匀采样 + 邻居补偿），在 token 限制内最大化保留信息量
- AI 以第一人称生成你的人生经历叙事

### 📤 导出与分享
- 下载 HTML 报告（离线可查看）
- 下载 MD 报告（可编辑）
- 📋 **一键复制人生经历**——粘贴给任何 AI，对方立刻了解你

### 🔒 隐私
- 纯前端架构，所有数据在浏览器本地处理
- AI 分析通过你自己的 API Key 直接调用
- 我们不碰你的任何数据

### 🃏 命运塔罗（附赠）
- 基于 22 张大阿尔卡那的 AI 占卜
- 三牌阵 + 命运画像 + 正/逆位随机
- 可导入观己生成的人生经历，占卜更贴合你的实际人生

## 🚀 快速开始

### 在线使用

直接打开 `index.html` 或 `app.html` 即可使用。观己是纯静态页面，无需任何后端。

### 本地运行

```bash
# 任何静态服务器都可以
npx serve .
# 或直接用浏览器打开 app.html
```

### 使用流程

```
1️⃣ 导出聊天记录 → 得到 TXT 文件
2️⃣ 打开观己 → 上传 TXT 文件
3️⃣ 配置你的 API Key（自己的，我们不经手）
4️⃣ 点击"开始分析"
5️⃣ 收到人生经历报告 → 复制/下载
6️⃣ 粘贴给茵茵或任何 AI → AI 从此了解你
```

## 🏗 技术架构

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ TXT 聊天记录  │ →  │ DataCleaner   │ →  │ AIClient      │
│ (微信/QQ导出) │    │ 解析/清洗/    │    │ AI API 调用   │
│              │    │ 格式标准化    │    │ (OpenAI/Gemini)│
└──────────────┘    └──────┬───────┘    └──────┬───────┘
                           │                   │
                           ▼                   ▼
                    ┌──────────────┐    ┌──────────────┐
                    │ 采样算法      │    │ AI 分析引擎   │
                    │ 时间分层      │    │ 三步 Pipeline │
                    │ 均匀采样+邻居 │    │ 人生叙事生成  │
                    └──────────────┘    └──────┬───────┘
                                              ▼
                                     ┌────────────────┐
                                     │ 人生经历报告     │
                                     │ HTML / MD / 复制 │
                                     └────────────────┘
```

### 核心模块

| 模块 | 类/文件 | 功能 |
|------|---------|------|
| **数据清洗** | `DataCleaner` | 解析微信/QQ 多种 TXT 格式，系统消息过滤，无效字符清理，时间戳标准化 |
| **AI 客户端** | `AIClient` | OpenAI 兼容 + Gemini 双协议，3 次自动重试，5 分钟超时，Unicode 清理 |
| **分析引擎** | `AIEngine` | 三步 Pipeline：数据预处理 → AI 分析 → 报告生成 |
| **采样算法** | `SamplingStrategy` | 时间分层 + 均匀块采样 + ±3 邻居补偿，在 token 限制内最大化信息量 |
| **报告生成** | `ReportGenerator` | 生成 HTML/MD 报告，含情绪可视化图表 |

## 💡 常见问题

**Q: 上传的数据安全吗？**
A: 所有数据读取、清洗、分析全在你的浏览器本地完成，没有任何文件上传到服务器。AI 分析使用你自己的 API Key 直连，我们不中转任何数据。

**Q: 支持哪些聊天记录格式？**
A: 支持微信和 QQ 导出工具生成的 TXT 文件，兼容多种时间戳格式（ISO 8601、中文格式、Unix 时间戳等）。

**Q: 需要什么 AI 模型？**
A: 任何支持聊天补全的模型都可以。推荐 DeepSeek V4 Flash（性价比高）或 GPT-4o（质量好）。你自己提供 API Key。

**Q: 分析结果可以导入其他 AI 产品吗？**
A: 可以。点击"复制人生经历"按钮，内容可直接粘贴到茵茵、ChatGPT、Kimi 等任何 AI 产品的对话框中。
